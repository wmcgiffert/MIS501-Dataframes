# MIS 501 — Lecture 10: Dataframes

Student starter for the coffee-shop terminal. The run cell is a menu: take an order (saved onto `sales.csv`), view the menu, or show reports. Polars reads each CSV into a dataframe. Taking an order appends rows to `sales.csv`, so the sample week changes once someone rings up a ticket.

Fill in the functions in `lecture_10_dataframes.py`; the demo cell and the run cell are already written.
